Pasang ke Skrin Utama (Android)

Punca Tiada Pilihan di Chrome:

Anda sedang membuka fail secara terus (file:///). Dasar keselamatan Google Chrome menghalang pilihan "Add to Home Screen" jika fail tidak dihoskan melalui Web Server (HTTP / HTTPS).

1 Cara Membuka Melalui Web Server (Percuma):

Untuk membolehkan Chrome Android memaparkan ikon pasang secara automatik, hoskan fail index.html ini menggunakan mana-mana perkhidmatan percuma berikut:

  • Vercel / Netlify / GitHub Pages: Muat naik fail index.html dan buka pautan HTTPS di Chrome.
  • Local Network / Live Server (VS Code): Buka pautan IP tempatan (cth: http://192.168.1.X:5500) di telefon Android anda.

2 Langkah Tambah ke Skrin Utama:

Tekan butang Menu 3-Titik di penjuru atas kanan Chrome.
Pilih "Add to Home screen" atau "Install app".
Tekan "Install" / "Add". Ikon KroketPro akan muncul di skrin utama telefon anda seolah-olah aplikasi natif!
